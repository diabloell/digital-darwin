# Digital Darwin

Локальная эволюционная стратегия и лаборатория искусственной жизни. Выберите линию, развивайте её через наследуемые адаптации и наблюдайте, как она конкурирует за пищу на процедурной планете.

## Запуск

Нужен **Node.js 24.3 или новее**. В папке проекта выполните одну команду:

```sh
node scripts/serve.mjs
```

Откройте **http://127.0.0.1:5173**. Установка пакетов не нужна. Сборка выполняется автоматически перед запуском. Для остановки сервера: Ctrl+C. Сервер слушает только loopback, публичного деплоя нет. При наличии npm можно использовать `npm start`.

Для рекомендуемого режима нажмите «Начать игру», выберите основателя и нажмите «Запустить» под картой. В наблюдателе можно сразу запустить время или выполнить один шаг. Колесо мыши масштабирует карту, перетаскивание перемещает камеру, клик выбирает организм. Кнопка «Выбрать организм» также открывает реальную особь. Space включает/останавливает время вне полей и кнопок; стрелки и +/- управляют камерой, Escape снимает выбор. Новый seed создаёт новый мир на паузе.

## Проверки

```sh
npm ci
npx --no-install playwright install chromium
npm run verify
```

Для проверки по отдельности используйте `npm run typecheck` (TypeScript strict, включая тесты), `npm run build`, `npm run lint`, `npm run test:unit`, `npm run test:integration` и `npm run test:e2e`. Полная матрица включает два прогона по 10 000 тиков со сравнением хешей и замер с 5 000 стартовых организмов. Журналы, JSON и скриншоты сохраняются в `outputs/verification/`; путь можно задать через `DD_EVIDENCE_DIR`. E2E запускает штатный HTTP-сервер на свободном порту и проверяет собранное приложение с реальным Worker. Для заранее установленного Chromium укажите путь в `DD_BROWSER`.

GitHub Actions повторяет матрицу для pull request и прикладывает артефакт `digital-darwin-verification`.

Для отдельного прогона используйте `npm run simulate -- --seed dd01-example --ticks 10000 --profile --output outputs/example.json`. Интервалы настраиваются через `--checkpoint-every` и `--audit-every`. Сценарии без пищи и размножения доступны через `--no-food` и `--no-reproduction`. Поддерживаются `--width` и `--height`.

## Структура

- `src/core/`: независимый движок и seeded RNG; без DOM, часов и сети.
- `src/worker.ts`, `src/protocol.ts`: планирование тиков и типизированные сообщения.
- `src/app.ts`, `src/style.css`, `index.html`: карта Canvas, контролы, инспектор, график.
- `apps/cli.ts`: тот же движок без браузера, SHA-256 полного состояния и измерения.
- `tests/`: инварианты и интеграционные сценарии.
- `docs/spec/`: копии доступной Notion-документации, включая планы последующих этапов.
- `reports/DD-01.md`, `reports/latest.json`: фактически выполненные проверки и ограничения.

Canvas/DOM и встроенные тесты Node выбраны вместо рекомендуемых React/Vite/PixiJS/Vitest/pnpm из-за недоступного менеджера пакетов и DNS. Это осознанное отклонение DD-00, а не утверждение об эквивалентности всех инструментов. Подробности и модель - в `ARCHITECTURE.md` и `docs/adr/001-dd00.md`.

## Репозиторий и перенос

Целевой репозиторий: https://github.com/diabloell/digital-darwin. Изменения DD-00 подготавливаются в ветке `dd-00-first-working-slice`; `main` не перезаписывается. Если подключение GitHub недоступно, скопируйте содержимое проекта в локальный checkout репозитория, исключив `dist`, `node_modules`, `tools`, `work`, `outputs` и `.git`, затем:

```sh
git switch -c dd-00-first-working-slice
git add .
git commit -m "Implement DD-00 living simulation and verification"
git push -u origin dd-00-first-working-slice
```

Не переносите каталог `.git` поверх другого checkout. PNG-скриншоты и JSON/логи в `reports/` служат доказательствами; при переносе их можно включить в коммит. Никаких ключей, секретов, облачных API или телеметрии приложению не требуется.

## Наследственность и эксперименты DD-02

График показывает численность или среднее любого из четырёх генов. Цвет точек переключается по признаку, гистограмма показывает распределение скорости живых организмов, а инспектор выводит геном и фенотип.

```sh
node apps/experiments.ts outputs/dd02/experiments.json
npm run simulate -- --seed dd02-example --ticks 10000 --evolution --output outputs/dd02/example.json
```

Доступны `--rule selection|neutral|dd01`, `--mutation-rate`, `--mutation-strength` и `--resource-scale`. Методика и единицы описаны в [генетических метриках](docs/genetic-metrics.md). Итоговые проверки и результаты — в [отчёте DD-02](reports/DD-02.md).

## Родословные и история DD-04

Выберите организм и откройте «Родословная». Из карточки можно перейти к родителю, основателю или линии. «Линии» показывает крупнейшие и недавно вымершие линии. Выбор линии обводит её живых представителей. «События» содержит фильтруемый журнал, из которого можно открыть связанную карточку.

[Определения и пороги событий](docs/history-metrics.md) · [Границы доступной истории](docs/adr/004-dd04-history-retention.md)

## Сохранения DD-05

Раздел «Миры и сохранения» хранит несколько миров в IndexedDB и поддерживает экспорт и импорт JSON. Мир восстанавливается на сохранённом тике, на паузе. [Руководство](docs/saves.md) · [Формат](docs/world-snapshot.md)

[Руководство по лаборатории](docs/experiment-lab.md) · [Схема декларации, архива и метрик](docs/experiment-definition.md). Эталонные headless-серии запускаются командой `node apps/lab.ts all outputs/lab`.

### Игровой режим DD-07

Запустите `npm ci` и `npm run dev`, затем выберите «Начать игру» или «Настроить новую игру». Для первого прохождения выберите `coral-42`, среду «Сад» и основателя №1. Запустите время, накопите 5 EP и попробуйте «Усвоение», затем «Раннее размножение». Метки и график отражают реальные результаты рождаемости, наследования и выживания. Слоты в разделе «Миры и сохранения» работают и для игровых миров. Сценарии и команды воспроизведения приведены в [отчёте DD-07](reports/DD-07.md).

### Консоль эволюции DD-08

Карта и управление временем находятся на первом экране. «Начать игру» запускает стандартный сценарий, «Настроить новую игру» позволяет выбрать seed и среду. Верхняя полоса показывает состояние мира и выбранной линии, справа расположены EP и адаптации. Под картой доступны мини-графики. Родословные, сохранения и лаборатория находятся в аналитической части. [Руководство](docs/user/evolution-console.md)

### Планеты DD-09

В «Настроить новую игру» отметьте «Процедурная планета». Seed задаёт базовые условия и связанные зоны на карте. В списке «Слой» доступны пища, базовый свет, тепло, влага и плодородие. Планетарная панель показывает текущую фазу света. Для примера подходит `coral-42` в Саду с основателем №73. [Условия и единицы модели](docs/adr/009-dd09-planet.md) · [Отчёт DD-09](reports/DD-09.md)

### Дерево эволюции DD-10

В «Настроить новую игру» включите «Дерево эволюции». На панели игры появляются текущие предложения, а в раскрываемом дереве видны зависимости, попытки и живые носители. После десяти завершённых программ, при достаточной истории размножения, доступны «Хранители пятен» и «Дальние разведчики». [Правила](docs/adr/010-dd10-evolution-tree.md) · [Отчёт](reports/DD-10.md)

### Экология DD-11

В «Настроить новую игру» включите «Экология и кризисы». В консоли появятся крупнейшие линии-конкуренты, данные по нишам и слои «Давление», «Кризис» и «Заявки на пищу». Кризисные клетки медленнее восстанавливают еду до снижения давления. Опция совместима с процедурной планетой и деревом. [Модель](docs/adr/011-dd11-ecology.md) · [Отчёт](reports/DD-11.md)

### Локальный кандидат 0.1.0-rc.1

**Из исходников:** установите Node.js 24, запустите `npm ci`, затем `npm run dev`. Откройте `http://127.0.0.1:5173`. «Начать игру» запускает рекомендуемый режим. «Настроить новую игру» позволяет сменить seed, среду и сочетание прежних механик.

**Переносимая папка:** выполните `npm run release:build`. В `outputs/release/digital-darwin-0.1.0-rc.1` входят сборка, локальный запускатель и манифест SHA-256. В этой папке достаточно `node start.mjs`. [Инструкция](docs/release/START.md) · [Release notes и ограничения](docs/release/RELEASE-NOTES.md)
