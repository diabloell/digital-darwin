# Digital Darwin 0.1.0-rc.1

- «Начать игру» объединяет планетарные ресурсы, дерево эволюции и конкуренцию за еду.
- Новый баланс Game v3 добавляет по 1 EP за первые восемь рождений линии. Развилке нужны десять малых попыток, 800 тиков и шесть потомков. После десяти малых попыток EP остаются доступны для специализации.
- В консоли появились обучение, просмотр начальной клетки основателя, подсказки о следующем решении и сводка при вымирании. Повтор использует тот же seed и настройки. Сохранённые миры остаются в слотах.
- Классические режимы, лаборатория и прежние форматы остаются доступными. Старые сохранения используют собственную версию баланса.
- Кандидат рассчитан на локальный запуск. Работоспособность проверена автоматически. Интерес и удобство для разных игроков требуют отдельной оценки. Не каждая живая линия получит достаточно потомков или EP для развилки. Кризис — условная ресурсная модель.
