# Запуск Digital Darwin 0.1.0-rc.1

1. Установите Node.js 24. Распакуйте папку игры.
2. Откройте терминал в папке с `start.mjs`. Выполните `node start.mjs`.
3. Откройте в браузере `http://127.0.0.1:5173`. Нажмите «Начать игру» и выберите основателя.
4. Запустите время под картой. Подсказка «Как играть» объясняет EP, программы и вымирание. Остановить сервер можно клавишами Ctrl+C.

В собранной папке устанавливать npm-зависимости не требуется. Сервер слушает только адрес этого компьютера. Сохранения живут в профиле браузера для указанного адреса и порта. Для переноса используйте экспорт файла. Если меняете порт через переменную PORT, откройте адрес из терминала и импортируйте нужные сохранения.
