# Лаборатория экспериментов DD-06

Откройте «Лаборатория экспериментов» под графиками наблюдателя. Выберите пресет, задайте по одному уникальному seed на строку, длительность и интервал. Число seed задаёт число независимых реплик на условие. Гипотезу, размеры мира и объявленные различия редактируют в раскрывающейся JSON-декларации. Поля seed, длительности и интервала над редактором имеют приоритет. После запуска используется проверенная копия декларации. Изменение содержания образует новый scenarioHash.

Запустите серию и следите за прогрессом. «Остановить» завершает текущий пакет. Уже завершённые реплики сохраняются, начатая отмечается cancelled, остальные not-run. Выберите метрику, seed и базу для парной разницы. В среднем графике линия представляет среднее, вертикальный отрезок — наблюдаемые минимум и максимум. Таблица выводит все реплики, в том числе вымершие и незавершённые. Терминальные метрики без временного ряда доступны в таблицах.

Экспортируйте JSON, CSV и Markdown. Архив хранит последние восемь серий с привязкой к адресу и профилю браузера. Запись видна после успешной транзакции. Закрытие страницы прекращает расчёты, результаты уже архивированных серий остаются. Лаборатория использует отдельный Worker и IndexedDB, сохранения миров DD-05 находятся в другой базе.

## Headless

```sh
node apps/lab.ts all outputs/lab
node apps/lab.ts LAB-E04 outputs/lab
node apps/lab.ts definition.json outputs/lab
node apps/lab.ts --check outputs/lab/LAB-E04/series.json
```

Ctrl+C прекращает серию между пакетами. Реплики записываются отдельными атомарными файлами; повтор не перезаписывает существующий каталог. Автоматического продолжения частичной серии нет. Итоговая папка содержит исходную декларацию, отдельные записи, сверяемый архив JSON, скалярные интервальные и итоговые метрики CSV, Markdown и замеры. [Схема и протокол](experiment-definition.md)
