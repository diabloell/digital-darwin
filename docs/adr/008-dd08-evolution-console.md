# ADR 008 — Консоль эволюции

Фаза DD-08 меняет композицию DOM и оформление. Панели сохраняют существующие точки входа и команды. Состояние игры меняет Worker. При создании и восстановлении мира остаётся прежний порядок действий. На новом запуске включён наблюдатель, игра начинается по явной команде, основателя выбирает игрок.

Кадр Worker передаёт три последних фактических события из существующей истории. Верхняя полоса отдаёт приоритет критическому событию из этого окна, а предупреждение о вымирании собственной линии берётся из состояния игры. Новые показатели производятся в интерфейсе из ограниченных рядов. История и снимок сохраняют прежнюю схему и объём хранения.

Камера фокусируется на первом живом представителе по порядку кадра. Фокус выполняется при выборе, восстановлении и явном нажатии. Автоматического сопровождения каждый тик нет. Пользователь может отдалить и вернуть полный обзор. Звёздная система и планета служат визуальным представлением. Характеристики цифрового мира поступают из кадра.
