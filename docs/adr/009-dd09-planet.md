# ADR 009 — Планетарные условия v1

«Процедурная планета» в настройках новой игры включает `config.planet = 1`. Остальные режимы используют прежнюю генерацию. Среда «Сад», «Дефицит» или «Без ресурсов» по-прежнему задаёт множитель начальной еды и её роста (1, 0,30 или 0) поверх выбранной генерации.

## Профиль и клеточная карта

Все индексы безразмерны. На панели и карте они показаны на шкале 0–100. Тепло не выражено в градусах, влажные зоны не означают океаны. Каждая планета создаётся потоком `Rng('planet-v1:' + seed)`, независимым от потока организмов. Для трёх последовательных равномерных значений u, v, w в [0, 1):

- Базовый свет L = 0,55 + 0,45u.
- Базовое тепло T = 0,20 + 0,58L.
- Базовая влага W = clamp(0,31 + 0,61v − 0,20T, 0, 1).
- Геологический индекс G = 0,44 + 0,55w.

Из того же потока строятся две периодические сетки узлов 4×4 и 6×6. Между узлами применяется сглаженная билинейная интерполяция, включая границу тороидального мира. Локальные рельеф r и бассейн b находятся в [0, 1]. Клетка вычисляет:

- Свет l = clamp(L × (0,62 + 0,38r), 0, 1).
- Тепло t = clamp(T + 0,38(l − 0,81L) − 0,19(r − 0,5), 0, 1).
- Влага m = clamp(W + 0,76(b − 0,5) − 0,25(r − 0,5) − 0,28(t − T), 0, 1).
- Плодородие = clamp(G × (0,42 + 0,58l) × (0,12 + 0,88m) × (1 − 0,85|t − 0,60|), 0, 1).

Четыре карты округляются до целых 0–100. Влажной считается клетка с индексом влаги не ниже 60. Для индекса плодородия F ёмкость C = 5200 + 95F, стартовая пища = floor(0,94C × масштаб), базовый рост B = floor((105 + 5,50F) × масштаб). Внутренняя единица запасов — тысячная доля единицы энергии в интерфейсе.

## Цикл и сохранение

Период света — 320 тиков. Для фазы p = tick mod 320 сила цикла s = min(p, 320 − p), свет = 72 + 46s/160 процентов базового. Рост в клетке с индексом влаги M равен floor(B × (11520 + (26 + floor(0,33M))s) / 16000). Влага усиливает отклик. Прирост ограничен свободной ёмкостью, проходит через `audit.grown` и доступен обычному питанию. Генотипы, перемещение, метаболизм и EP используют прежние правила.

Версия WorldSnapshot остаётся 1. Для планеты конфигурация содержит версию генератора, seed, размер, масштабы и параметры, а снимок хранит тик, фактическую пищу, ёмкость, базовый рост и RNG организмов. Карты пересчитываются из того же генератора и seed. Поток генерации после создания не используется. Фаза следует из сохранённого тика. Восстановление проверяет ёмкость и базовый рост против рассчитанной карты. Старые снимки без поля открываются как прежние миры. Планетарный файл требуется открывать в DD-09 или новее.

Планета, соседние тела и орбиты в DD-08 остаются схемой. Новый слой карты меняет только отрисовку. Контур физики, движение воды и эффекты соседних тел вне модели.
