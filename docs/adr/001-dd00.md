# ADR-001: self-contained DD-00 vertical slice

Date: 2026-11-21. Status: accepted for this constrained DD-00 implementation.

Context: local directory contained no code. Notion parent, development plan and six child specifications were accessible; copies are in docs/spec. GitHub target contains only its initial heading README. Node 24.22.1 and runtime Playwright/Chrome are available. npm/pnpm/tsc are absent; registry.npmjs.org and github.com cannot be resolved from the shell. GitHub connector has push permission. Public deployment is not authorized.

Decision: implement pure TypeScript core, module Worker, DOM/Canvas browser adapter and Node built-in tests without network dependencies. Use built-in type stripping for build/run, explicit strict tsconfig for later compiler validation. Alternatives were waiting for package installation, shipping an unexecutable dependency manifest, or reducing the biology to a visual demo. A runnable slice with honest verification gaps is preferable. Do not label transpilation as typecheck. React/Vite/Pixi/Vitest/pnpm remain recommended alternatives; this implementation does not claim to use them.

RNG/scheduling (ADR-002 scope): xoshiro128** with serialized state; canonical ID iteration; one intent per pre-existing live organism, phases and deferred newborn insertion. Float coordinates limit determinism to tested runtime. Proportional equal food allocations were chosen over ascending-ID first-wins because equal demands should not favor founders. Ascending IDs still assign seeded behavior and mutations reproducibly.

Energy (ADR-003 scope): Int32 resource quanta, integer reserves and explicit rounding/sinks. Local energy equations are tested. Environment regrowth is external input; there is no conservation claim for a closed universe. Initial calibration with growth factor 7 collapsed (1000 -> 0, 117 births / 1117 deaths), despite unused food elsewhere. Resting on rich cells alone did not resolve the resource bottleneck. Factor 28 and minimum 2 were selected as the DD-00 garden balance. The original failing ecological outcome is preserved in reports/initial-model-extinction.json. Updated model achieves 4346 living agents after 5000 ticks for dd00-verification; that does not guarantee stability for all seeds or infinite time.

Storage (ADR-004 scope): typed grid fields plus record organisms, monotonic stable IDs and destination-cell claims. Full organism SoA is deferred pending profiling; no empty future packages. Measured performance is evidence, not a capacity guarantee.

Persistence (ADR-005 scope): no saves/replay in DD-00. Complete canonical state is for verification only; it is not an importable versioned snapshot. This avoids falsely promising DD-05.

Protocol/retention (ADR-006/007 scope): typed commands, versioned engine result, epoch for reset; transfer position/ID/food buffers, acknowledge periodic frames, capped 300 population samples. No unbounded lineage/event archive. Full request deduplication and public extension registry are deferred.

Original verification consequences: strict compiler cannot run here; final milestone must remain PARTIAL. Browser loopback requests receive ERR_NETWORK_ACCESS_DENIED, so Playwright fulfills actual dist resources through local offline routes and runs the real module Worker. This verifies browser behavior but not end-to-end TCP serving. Screenshots are actual browser captures. The server startup is observed independently.

DD-00-FIX update: keep the existing DOM/Canvas, Worker, core and headless CLI. Pin TypeScript, Node declarations and Playwright as development dependencies, install with `npm ci` and check all TypeScript with strict `tsc --noEmit`. Browser verification uses the ordinary loopback HTTP server. GitHub Actions runs the same verification matrix and retains evidence. Current results are recorded in `reports/latest.json`.
