# ADR 014 · Окно первой программы

В DD-14 новый рекомендуемый мир использует Game v4. Первая малая программа длится 160 тиков. Остальные цены, сроки, изменения генов, правила внедрения и движок сохраняют прежние значения. Правка даёт первой программе больше возможностей дождаться новых рождений. Уже живые организмы не получают признак. Программа без внедрений по-прежнему завершается.

Правило срока зависит от версии Game и номера покупки. Продолжительность в файле проверяется по этому же правилу. Снимки v1–v3 исполняются по своему балансу, в том числе при повторе seed из старой игры. Формат контейнера снимка сохраняется. Кадр Worker по необходимости содержит однобайтовую маску последней адаптации в порядке ID, построенную из существующих меток. Маска не сохраняется и не участвует в расчёте симуляции.
