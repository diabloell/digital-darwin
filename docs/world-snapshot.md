# Формат WorldSnapshot v1

Файл `.ddworld.json` — UTF-8 JSON с полями `manifest` и `payload`. Payload — строка с JSON состояния. Двойное представление позволяет проверить точные байты состояния, до разбора его структуры. Верхняя граница файла — 32 МиБ. Порядок ключей биологического конфига сохраняется, в том числе для исторического canonical SHA-256.

Манифест содержит `format`, `engine`, `genome`, `evolution`, `compatibility`, `createdAt`, `name`, `seed`, `tick`, `width`, `height`, `population`, `config` и `checksum`. SHA-256 считается по UTF-8 от JSON-массива следующих значений в фиксированном порядке:

```
[format, engine, genome, evolution, compatibility, createdAt, name,
 seed, tick, width, height, population, payload]
```

Копия `config` в манифесте сравнивается со значениями внутри проверенного payload. Поддерживается точное сочетание формата 1, Engine 0.3.0, генома и правил эволюции текущей сборки. SHA-256 обнаруживает повреждение и расхождение данных. Он не удостоверяет автора и не заменяет валидацию файла.

Внутри payload:

- `engine` включает конфиг, четыре слова RNG, тик, счётчики, следующее ID, живых с геномами, состоянием движения и родителями, пищу, ёмкость и прирост каждой клетки. Также включены аудит, ожидаемый баланс пищи и события последнего тика.
- `history` включает живые записи, FIFO умерших, закреплённых предков, ссылки и число потомков, агрегаты всех основателей, счётчики событий и FIFO, последний отсчёт кризисов, cooldown и накопители незавершённой группы событий.
- `samples` содержит до 300 сохранённых точек наблюдателя, без изменения лимитов DD-04.

Ресурсы сериализуются целыми числами и восстанавливаются в Int32Array. Состояния организма хранятся числами JavaScript двойной точности. Float32-буферы карты производятся заново для следующего кадра. Они не участвуют в биологической динамике и не входят в файл.

Версии проверяются перед разбором payload. Неизвестная схема отклоняется. Миграций пока нет. В будущей версии преобразование должно быть явным, отдельным и покрытым тестом. Фиксированный пример v1 хранится в `tests/fixtures/dd05-v1.ddworld.json`.
