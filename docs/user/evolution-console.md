# Консоль эволюции

Запустите `npm ci` и `npm run dev`. Откройте адрес из вывода сервера. На мобильном экране карта стоит сразу под телеметрией, а решения расположены под управлением временем.

1. Нажмите «Начать игру» для стандартной среды. «Настроить новую игру» позволяет выбрать seed и среду. Выберите основателя и запустите время.
2. Под картой доступны пауза, один тик и скорость. Колесо над картой меняет масштаб, за её пределами прокручивает страницу. Сфокусируйте карту клавишей Tab, затем используйте стрелки, +/−, Home или Enter. «К линии» наводит камеру на живого представителя, ⌖ восстанавливает обзор.
3. Выберите организм на карте и откройте «Инспектор». В «Аналитике» можно открыть его родословную, выделить линию, переключить график и изучить историю.
4. Справа видны статья начислений EP, бюджет и три карты. Прогресс показывает тики текущей программы. Итоги показывают живых носителей среди живых представителей выбранной линии. Для проверки сыграйте `coral-42` в Саду за №1, купите усвоение и затем раннее размножение.
5. Верхние ссылки раскрывают сохранения и лабораторию. Сохраните мир на паузе, перезагрузите страницу и загрузите слот. Панель лаборатории работает с отдельными экспериментами.
6. Раскройте «Звёздная система» в блоке планеты. Это декоративный вид. Ресурсы и численность берутся из текущего цифрового мира.

Четыре мини-графика используют до 36 последних отсчётов для каждого ряда. Ось времени учитывает тики, вертикальная шкала подстраивается под диапазон каждого ряда. Подробные шкалы доступны в аналитике. Энергия под картой усреднена по живым организмам мира. Четвёртый график показывает средний ген последней программы по живым представителям выбранной линии, до программы показывает число маркированных носителей. Изменения в правой панели считаются между двумя последними отсчётами. Последние три события из истории идут от нового к старому. Полоса выделяет критическое событие из этого окна, если оно есть.
